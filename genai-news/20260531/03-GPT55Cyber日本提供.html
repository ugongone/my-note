GPT-5.5-Cyber、日本の重要インフラへ

サイバー防御特化AIがメガバンクに渡る。生成AIが安全保障協力の対象になる時代。

1. 何が発表されたか

来日した OpenAI の Jason Kwon 最高戦略責任者（CSO）が、サイバー防御に特化したモデル「GPT-5.5-Cyber」を日本の一部企業・機関に提供する方針を表明した。片山さつき財務相は Kwon 氏との会談後、一部の金融機関がすでに同モデルへのアクセスを得たと会見で述べ、「日本の金融機関のサイバー攻撃への防御能力を強化する大きな一歩」と評価した。報道では三菱UFJ・三井住友・みずほの3メガバンクが対象とされる。

時制に関する注記: 朝日新聞のKwon氏インタビューでは「これから提供する（soon provide）」とされる一方、財務相会見では「すでに一部金融機関がアクセスを取得済み」と報じられた。提供は段階的に進行中で、対象機関名は公式には非開示。

2. 日米サイバー協力の文脈

この提供は単発の商談ではなく、15の重要インフラ分野（金融・電力など）を対象とする日米サイバーセキュリティ協力の枠組みに組み込まれている。OpenAI 別幹部が今週、日本政府当局者とこの15分野について協議したと Kwon 氏は明かしており、製造業へのアクセス拡大も示唆した。報道によれば、この取り組みはベッセント財務長官の東京訪問中に外交的に調整され、米国の輸出管理を踏まえた移転となった。36のメンバーから成る官民ワーキンググループが調整にあたり、OpenAI・Anthropic・メガバンク等が同席する。

背景には、Anthropic が4月に公開した Claude Mythos がゼロデイ脆弱性を自律的に発見・悪用しうる能力を示し、世界の金融機関が防御策の構築を迫られている事情がある。英国 AI Security Institute（AISI）の報告では、GPT-5.5 と Mythos はいずれも模擬サイバー攻撃試験の全課題をクリアし、同等水準と評価された。日本のメガバンクはこの脅威に「待たずに」対応する形となった。

3. OpenAI 対 Anthropic の技術標準競争

OpenAI

GPT-5.5-Cyber を「Trusted Access for Cyber」という審査制プログラムで提供。米国・カナダ・韓国に続き日本へ展開し、「OpenAI for Countries」構想で第1フェーズだけで10以上の国・地域提携を狙う。検証済みの防御者にツールを優先的に渡す、というゲートキーピングが設計思想。

Anthropic

Claude Mythos を Project Glasswing パートナーに限定提供。日本でも政府・金融機関への提供が見込まれ、NEC・日立・富士通の3社が同週そろってAnthropicと協業を表明（本週報④）。日本市場で OpenAI と真正面から技術標準を競う構図になった。

4. デュアルユースという論点

Kwon 氏は、サイバー攻撃から守る技術が攻撃にも転用されうるデュアルユースの性質を認め、「信頼できる相手にのみ提供することの重要性」を強調した。GPT-5.5-Cyber は攻撃・防御の両用途を想定して設計されており、だからこそアクセスを審査制で絞るという論理が貫かれている。一方で、私企業が主導する強力なAIをいかに政府が統治するか、という難問は残る。

引用: 「cybersecurity is a team sport」── 政府と民間すべてが協力する必要がある、と Kwon 氏。OpenAI の原則は「政府に情報を伝え、次に来るものを予見できるようにすること」だという。
  • -防御側の利点：検証済みの防御者が攻撃者より先に高性能ツールを得られる
  • -リスク：同じ脆弱性発見能力が攻撃に転用されうる／統治の枠組みが追いついていない

5. まとめ：AIが安全保障インフラになる

AIサイバーモデルが、兵器システムや情報共有条約と並んで二国間の安全保障合意の「品目」になり始めた──これが今回の本質だ。フロンティアモデルが消費者向けプロダクトではなく国家の重要インフラとして扱われ、輸出管理や外交交渉の対象となる。日本にとっては防御能力の底上げという実利がある一方、提供主体である米企業への依存や、攻撃転用リスクの統治という課題も同時に抱え込むことになる。OpenAI と Anthropic の標準競争が、日本の重要インフロ防衛の現場で具体化していく点に今後も注目したい。
