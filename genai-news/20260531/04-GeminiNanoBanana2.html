Nano Banana 2 / Pro が一般提供（GA）

Gemini 3.1 Flash Image がエンタープライズGAへ。動画→画像生成という新たな入口。

1. 何が発表されたか

Google は2026年5月29日、画像生成モデル Nano Banana 2（Gemini 3.1 Flash Image） と Nano Banana Pro（Gemini 3 Pro Image） を Gemini Enterprise Agent Platform 経由で一般提供（GA）開始した。両モデルはエンタープライズ級のインフラとセキュリティ、SLA に対応し、アプリやワークフローに高品質な画像生成・編集を直接組み込めるようになった。開発者は Gemini API 経由でも利用できる（こちらは SLA 対象外）。

原 Nano Banana（2025）
Nano Banana 2 Preview（2/26）
GA（5/29）
補足: Nano Banana 2 そのものは2026年2月26日に Preview として公開済み。今週のニュースは「エンタープライズ向けの一般提供（GA）化」であり、新規モデル登場ではない点に注意。

2. 前モデルから何が変わったか

原 Nano Banana は2025年に登場し、数十億枚の画像生成に使われた人気モデルだった。Nano Banana 2 はそれを土台に、上位の Nano Banana Pro が持っていた高度な機能を Flash の速度で実現する位置づけになっている。公式が挙げる主な進化点は以下のとおり。

観点 原 Nano Banana（2025） Nano Banana 2 / Pro（現在）
対応入力テキスト・画像テキスト・画像・動画（Preview）
解像度標準解像度1K / 2K / 4K（高解像度出力）
テキスト描画限定的長文も読みやすく、誤りが減少
被写体の一貫性編集で崩れやすい複数生成・編集をまたいで維持
世界知識標準高度化（文脈に即した正確な画像）
来歴証明SynthIDSynthID + C2PA Content Credentials
補足: Pro 版（Gemini 3 Pro Image）はより要求の高いプロ／プロダクション用途向けで、世界知識とテキスト描画がさらに優れるとされる。2 版（Flash）は高ボリューム用途に最適化された速度重視のラインという棲み分け。

3. 新機能：動画→画像生成（Preview）

今回のGAで明示された目玉が「動画を入力として画像を生成する」機能（Preview）だ。動画からキーフレームを抽出したり、サムネイルを作ったり、動画の内容に基づいた静止画を生成したりできる。従来の「テキスト→画像」「画像→画像」に加え、動画を起点にする経路が加わったことで、映像ワークフローとの接続点が生まれた。

引用: 「Nano Banana 2 now supports video files as an input prompt. (...) the model now utilizes deep video understanding to analyze the visual context, specific subjects, and actions within video footage to generate context-aware images, including thumbnails, rich infographics, and more.」（Google Cloud Blog）

4. Gemini Omni との関係とマルチモーダル統合

Google は I/O 2026（5/19）で、あらゆる入力からあらゆるものを生成する動画生成モデル「Gemini Omni」を発表している。今回の Nano Banana 2/Pro が「動画を入力として静止画を出す」方向であるのに対し、Omni は「テキスト・画像・音声・動画から動画を生成・編集する」方向で、両者はマルチモーダルを別の角度から押し進める関係にある。画像生成が単独メディアのツールから、Gemini 系の汎用マルチモーダル基盤の一部へ統合されていく流れがはっきりしてきた。

Nano Banana 2 / Pro は入力にテキスト・画像・動画（Preview）を取り、出力はテキストと画像。Search グラウンディングや C2PA 来歴証明など、Gemini 基盤の機能を共有する。

補足: エンタープライズSLA対応のGAになったことで、PoC段階から本番組み込みへ移しやすくなった。4K出力やテキスト描画の改善は、そのまま制作の外注削減・内製化に効いてくる。

6. まとめ：画像生成主戦場の移動

Nano Banana 2 / Pro の GA は、単なる新モデル投入ではなく「Preview で人気を得たモデルを、エンタープライズが本番で使える形に固める」フェーズの動きだ。原 Nano Banana から見れば、解像度・テキスト描画・被写体一貫性・世界知識が底上げされ、さらに動画入力という新たな経路が加わった。画像生成の主戦場は、テキスト→画像の単機能ツールから、動画も含めた入出力マルチモーダルを束ねる汎用基盤（Gemini / Omni）へと移りつつある。OpenAI の画像・動画戦略との対抗構図の中で、Google は「速度の Flash」「品質の Pro」を両輪に据えてエンタープライズ領域を押さえにいった、と読める。
