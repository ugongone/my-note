OpenAI、サイバー防御特化AI「GPT-5.5-Cyber」を日本提供へ

元NSA長官ナカソネ取締役の来日と、政府・金融機関を狙う Trusted Access 戦略

発表の概要

OpenAI は2026年5月21日、サイバーセキュリティ特化モデル 「GPT-5.5-Cyber」を日本の政府機関および一部の重要企業向けに提供する方針を、都内で開催した記者会見で発表した。

来日したのはポール・M・ナカソネ取締役。米陸軍大将、米国家安全保障局（NSA）長官およびサイバー軍司令官を務めた人物で、現在は OpenAI 取締役。「日本によるChatGPT-5.5-Cyberへのアクセスを確かなものにすることに非常に成功した」と述べ、日本政府および金融セクターでの本格提供に向けた協議の手応えを示した。

提供される 4 製品ライン

GPT-5.5 Cyber

モデル

サイバーセキュリティに特化したフロンティアモデル。システム脆弱性の特定能力が極めて高いとされ、悪用リスクから一般公開はされない（5/7発表）。攻撃検知・防御に特化した推論を行う。

Trusted Access for Cyber (TAC)

枠組み

強力モデルへの「正当な防衛者」のみのアクセスを担保する申請・審査制プログラム。複数アクセスレベルがあり、GPT-5.5 Cyber は最上位ティア。本人確認、モニタリング、説明責任、ポリシーレビューが必須。

Codex Security

開発系

Codex 系のセキュリティ強化版。社内コードの脆弱性検知・修正の自動化を想定。

Daybreak

防御フロンティア

2026/5/12 に発表されたサイバー防衛特化のフロンティア AI サービス。脆弱性修正自動化を担う。

ナカソネ取締役の発言

「今週、日本の政策リーダーと対話を重ねてきたが、日本はすでに、AIとサイバーセキュリティ、そして国家のレジリエンスについて、非常に深く関与している。ただし、AIが政府、企業、そして重要インフラに統合される中で、サイバーセキュリティを切り離して考えることはできない」 — Impress Watch（5/21）
「高度なAIが正当な防衛者にとって有用なものになる。悪用から強力に保護されることを確実にする手助けをしていく。安全で信頼され、日本の重要なパートナーになる」 — ポール・ナカソネ氏 / Impress Watch
「日本によるチャットGPT5.5サイバーへのアクセスを確かなものにすることに非常に成功したと考えている」 — ANN（テレ朝NEWS）会見映像より

背景と含意

日本の能動的サイバー防御

2025年5月に成立した「サイバー対処能力強化法」を背景に、政府・重要インフラ事業者は能動的サイバー防御の体制整備を進行中。国家サイバー統括室の運用フェーズと、フロンティア AI の防御活用がちょうど重なるタイミング。

Anthropic Mythos との対抗軸

Anthropic はサイバー攻撃能力で知られる「Mythos」を Project Glasswing で限定提供（5/18週には Cloudflare が検証結果を公表）。OpenAI は同じ防御特化の枠で「サイバーエコシステム」全体提供で対抗する形となった。

金融機関への展開

「政府と金融機関の対策から開始」と公式言及あり。三菱UFJ・三井住友・みずほ等のメガバンクを中心に、重要インフラ事業者への段階展開が想定される（金融庁・日銀も5/22に金融機関へAI悪用攻撃対応を要請）。

地政学的選択軸

金融・政府向けAI選定は「性能」ではなく「どの国の企業が作ったか、データ保管はどこか」が主軸になりつつある。米国製の OpenAI / Anthropic は日米連携の文脈で優位、一方で日本のデータ主権論議も加速する。
